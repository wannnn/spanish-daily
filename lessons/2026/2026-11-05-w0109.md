## 基本資訊

- **單字：** deber
- **中文意思：**
  1. 應該（表示義務、建議），結構為 `deber + 原形動詞`
  2. 必須（表示較強烈的義務）
  3. 欠（金錢、人情等），結構為 `deber algo a alguien`
  4. 想必、應該是（表示推測），結構為 `deber de + 原形動詞`
- **詞性：** 動詞（規則 `-er` 動詞）

## 用法

- 最常見的用法是 `deber + 原形動詞`，表達「應該」做某事，帶有義務或建議的語氣，例如 `Debes estudiar más`（你應該多唸書）。
- 也可表示較強烈的「必須」，語氣介於單純建議與強制之間，依語境而定，例如 `Debemos respetar las leyes`（我們必須遵守法律）。
- 表示「欠」的意思時，結構為 `deber algo a alguien`，可以是金錢，也可以是抽象的人情，例如 `Te debo cien euros`（我欠你一百歐元）、`Le debo mucho a mi madre`（我欠母親很多（恩情））。
- `deber de + 原形動詞` 傳統上用來表達推測、猜想（「想必、應該是」），與表示義務的 `deber + 原形動詞` 在意義上不同，但在日常口語中這個區分常常被模糊，很多人直接用 `deber + 原形動詞` 來表示推測。
- 常見搭配：
  - `deber dinero`（欠錢）
  - `deberle la vida a alguien`（欠某人一命）
  - `debería + 原形動詞`（條件式，語氣較委婉的建議，相當於中文「也許應該……」）
  - `no deber nada a nadie`（不欠任何人）
- 常見固定表達：
  - `Debo decir que...`（我必須說……，用來引出坦白或評論）
  - `¿Qué le debo?`（我該付您多少錢？，在商店或餐廳詢問金額）
  - `Como es debido`（如應有的方式、妥當地）
  - `Debido a...`（由於……，源自 `deber` 的過去分詞，已固定為介系詞用法）
- 容易混淆的詞：
  - `deber` vs `tener que`：`deber` 偏向道德上、個人判斷上的義務或建議，語氣較溫和；`tener que` 強調外在情況所造成的必要性，語氣更強烈、更具強制性，例如 `Debes llamarla`（你應該打給她，出於禮貌或關心）而 `Tienes que llamarla antes de las seis`（你必須在六點前打給她，否則會有後果）。
  - `deber` vs `haber de`：`haber de + 原形動詞` 是較正式、書面或帶命運色彩的義務表達，使用頻率遠低於 `deber`，例如 `Había de llegar este día`（這一天終究會到來）。
- 學習者常見錯誤：
  - 混淆 `deber`（義務）與 `deber de`（推測），例如誤以為 `Debe de llover` 一定是指「必須下雨」，而其實是「應該快要下雨了」的推測語氣。
  - 用 `deber` 表達強烈、外部強制的義務時語感過弱，此時改用 `tener que` 更自然。
  - 誤用 `debo` 加名詞直接表達「欠」，忘記需要加受詞代詞或介系詞 `a`，正確應為 `Le debo dinero a Juan`，而非 `Debo dinero Juan`。

## 詞形變化

`deber` 是完全規則的 `-er` 動詞，所有時態的詞幹 `deb-` 保持不變，詞尾變化與其他規則 `-er` 動詞（如 `comer`）完全一致，沒有任何拼寫或重音上的特殊變化。由於 `deber` 本身已具有「應該、必須」的語意，命令式（Imperativo）的變化形式在實際口語中幾乎不會使用——直接命令某人「應該」做某事在語感上顯得多餘或不自然，因此下表雖列出完整變化形式，但例句部分將略過命令式。

| 人稱 | 變化 |
|---|---|
| yo | debo |
| tú | debes |
| él/ella/usted | debe |
| nosotros/as | debemos |
| vosotros/as | debéis |
| ellos/ellas/ustedes | deben |

## 例句

- **Presente：** *Debes tener cuidado con lo que dices.*
  你說話要小心一點。
  說明：`deber + 原形動詞` 表示現在的義務或建議，現在式規則變化。

- **Pretérito indefinido：** *Debí haberlo pensado mejor antes de aceptar.*
  我當時應該先想清楚才接受的。
  說明：`deber + haber + 過去分詞` 的結構表示對過去未做之事的後悔，簡單過去式規則變化。

- **Imperfecto：** *Cuando era niño, debía acostarme a las nueve.*
  我小時候必須九點就上床睡覺。
  說明：未完成過去式表示過去持續存在、具有習慣性的義務，規則變化。

- **Perfecto：** *No ha debido tratarte así; voy a hablar con él.*
  他不應該那樣對待你；我會去跟他談談。
  說明：現在完成式表示對最近發生之事的評價或譏責，`debido` 為規則過去分詞。

- **Futuro：** *El informe deberá estar listo antes del viernes.*
  這份報告必須在星期五前完成。
  說明：未來式常用於正式或書面語境中表達規定、要求，規則變化。

- **Condicional：** *Deberías descansar un poco; llevas todo el día trabajando.*
  你應該休息一下；你已經工作一整天了。
  說明：條件式是表達委婉建議最常見的方式，語氣比現在式的 `debes` 更柔和。

- **Subjuntivo：** *No creo que deba decírtelo todavía.*
  我不認為我現在應該告訴你。
  說明：主句表達懷疑或否定判斷（`no creer que`）時，從句動詞需用虛擬式。

- **推測用法（deber de）：** *Son las diez y no contesta; debe de estar dormido.*
  已經十點了他還不回覆；他應該是睡著了。
  說明：`deber de + 原形動詞` 表示根據現有線索所做的推測，與表義務的 `deber` 用法不同。

## 延伸學習

- **同義詞：** `tener que`（表示較強烈、外部強加的必要性）、`haber de`（較正式、書面的義務表達）
- **反義詞：** 沒有嚴格對應的反義詞；若指「沒有義務」，可用否定形式 `no tener que`（不需要）表達相對概念。
