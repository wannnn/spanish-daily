## 基本資訊

- **單字：** usar
- **中文意思：**
  1. 使用、利用（物品、工具、方法等）
  2. 穿、戴（衣物、配件等）
  3. 使用（服務、交通工具、語言等）
- **詞性：** 動詞（規則 -ar 動詞）

## 用法

- 最基本的意思是「使用」某個物品或工具，例如 `Puedes usar mi ordenador`（你可以用我的電腦）、`¿Cómo se usa esta máquina?`（這台機器怎麼用？）。
- 也常用於「穿、戴」衣物或配件，例如 `Siempre usa gafas`（他一直戴著眼鏡）、`Hoy uso una chaqueta nueva`（我今天穿了一件新夾克）。
- 可用於較抽象的「使用」，例如使用語言、方法或服務：`usar el español en el trabajo`（在工作中使用西班牙語）、`usar el transporte público`（使用大眾運輸）。
- 常見搭配：
  - `usar algo para + 動詞原形`（用某物來做某事）
  - `usar bien / mal algo`（善用／濫用某物）
  - `usar la cabeza`（動腦筋，引申用法）
- 常見固定表達：
  - `para uso exclusivo de...`（僅供……使用）
  - `sin usar`（未使用過的，形容全新的物品）
- 容易混淆的詞：
  - `usar` vs `utilizar`：意思幾乎相同，`utilizar` 較正式、常見於書面語或強調「有效利用」，`usar` 較口語、使用範圍更廣（也能指穿戴衣物，`utilizar` 較少這樣用）。
  - `usar` vs `llevar`：表示「穿戴」時兩者意思接近，但 `llevar` 更強調「當下正穿著」的狀態，`usar` 則也可表示「習慣性穿戴某種款式」。
- 學習者常見錯誤：
  - 誤以為 `usar` 一定要翻譯成「使用」，而忽略它也能表示「穿、戴」的意思。
  - 把規則動詞 `usar` 誤當成詞幹變化動詞，寫出不存在的形式（如誤寫成 `*uso` 以外的變體），其實 `usar` 完全規則，所有時態詞幹皆為 `us-`。

## 詞形變化

`usar` 是規則 -ar 動詞，所有時態的詞幹 `us-` 保持不變，只在詞尾依人稱與時態規則變化，沒有任何不規則形式。

## 例句

- **Presente：** *Siempre uso el mismo diccionario para estudiar español.*
  我學西班牙語時總是用同一本字典。
  說明：現在式描述習慣性、經常性的動作。

- **Pretérito indefinido：** *Ayer usé tu bicicleta para ir al trabajo.*
  昨天我用了你的腳踏車去上班。
  說明：簡單過去式描述一次已完成、有明確時間點的動作。

- **Imperfecto：** *Antes usaba lentes de contacto, pero ahora prefiero las gafas.*
  我以前戴隱形眼鏡，但現在比較喜歡戴眼鏡。
  說明：未完成過去式強調過去持續或習慣性的狀態，與現在形成對比。

- **Perfecto：** *Nunca he usado esta aplicación antes.*
  我從來沒用過這個應用程式。
  說明：現在完成式強調經驗，與說話當下仍有關聯。

- **Futuro：** *El próximo mes usaremos un nuevo sistema en la oficina.*
  下個月我們辦公室將會使用一個新系統。
  說明：未來式表達尚未發生但已預定的計畫。

- **Condicional：** *Yo usaría otro método si tuviera más tiempo.*
  如果我有更多時間，我會用另一種方法。
  說明：條件式搭配虛擬式表達假設情境下會採取的行動。

- **Subjuntivo：** *Es importante que uses casco cuando andas en bicicleta.*
  騎腳踏車時戴安全帽很重要。
  說明：`es importante que` 要求從句使用虛擬式表達必要性或建議。

- **Imperativo：** *Usa el cinturón de seguridad siempre que conduzcas.*
  開車時一定要繫安全帶。
  說明：命令式 `tú` 形式，用於給予直接指示或建議。

## 延伸學習

- **同義詞：** `utilizar`（較正式的「使用」）、`emplear`（使用、運用，常見於書面語或較正式語境）
- **反義詞：** （無明確的常用反義詞；語境相反的概念可用 `desechar` 表示「丟棄不用」）
