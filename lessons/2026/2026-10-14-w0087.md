## 基本資訊

- **單字：** para
- **中文意思：**
  1. 為了、為了⋯而（表示目的、用途）
  2. 給⋯（表示接收者）
  3. 對⋯來說（表示觀點、立場）
  4. 向⋯（方向）、到⋯為止（表示截止期限）
  5. 以便、用來（接不定詞，表示功能）
- **詞性：** 介系詞

## 用法

- `para` 最核心的意思是「為了」，表示目的或用途：`Estudio para aprender español.`（我學習是為了學會西班牙文。）
- 表示動作的接收者：`Este regalo es para ti.`（這個禮物是給你的。）
- 表示「對⋯來說」，引出觀點或立場：`Para mí, esta película es excelente.`（對我來說，這部電影很棒。）
- 表示方向或目的地：`Salimos para Madrid mañana.`（我們明天出發前往馬德里。）
- 表示截止期限或時間點：`Necesito el informe para el viernes.`（我需要在星期五之前拿到報告。）
- 接不定詞，表示功能或用途，相當於「用來⋯」：`Esta máquina sirve para hacer café.`（這台機器是用來煮咖啡的。）
- 常見搭配：
  - `para siempre`（永遠）
  - `para nada`（一點也不、完全不）
  - `para que`（為了讓⋯，後接虛擬式）
  - `¿para qué?`（為了什麼目的？）
  - `para colmo`（更糟的是）
  - `no es para tanto`（沒那麼嚴重）
- 容易混淆的詞：
  - `para` vs `por`：`para` 表示目的、用途或接收者，著重動作的**終點或目標**；`por` 表示原因、動機或「經由」的方式，著重動作的**起點或理由**。比較：`Lo hice para ti.`（我這麼做是為了給你，你是接收者）對比 `Lo hice por ti.`（我這麼做是因為你，你是動機）。
  - `para que`（連接詞，為了讓⋯，後接虛擬式）vs `para` 接不定詞（主詞相同時用不定詞，主詞不同時才用 `para que`）：`Estudio para aprobar.`（我學習是為了自己通過考試）對比 `Te lo explico para que entiendas.`（我跟你解釋是為了讓你理解）。
- 學習者常見錯誤：
  - 誤用 `por` 表達目的：應說 `Estudio para ser médico.`（我為了成為醫生而學習。），而非 `Estudio por ser médico.`
  - 主詞不同時仍使用不定詞而非 `para que`：應說 `Lo hago para que tú descanses.`，而非 `Lo hago para tú descansar.`
  - 混淆「對⋯來說」的 `para mí` 與受格代名詞用法，誤寫成 `para yo`：正確應為 `para mí`。

## 詞形變化

`para` 為不變化的介系詞，沒有性別、單複數變化，也不隨人稱或語境改變形式。

- 與冠詞 `el` 連用時**不會**產生類似 `a + el → al`、`de + el → del` 的縮寫形式：`para el niño`（給這個小孩）維持兩個獨立的詞。
- 後接代名詞時使用受格代名詞形式（`mí`、`ti`、`él/ella/usted`、`nosotros/as`、`vosotros/as`、`ellos/ellas/ustedes`），注意 `mí` 和 `ti` 帶重音符號以區別於所有格 `mi`、`ti` 本身不變但常與 `para` 搭配。

## 例句

- **目的：** *Trabajo mucho para ahorrar dinero.*
  我努力工作是為了存錢。
  說明：`para` 接不定詞 `ahorrar`，表示動作的目的。

- **接收者：** *Compré estas flores para mi madre.*
  我買了這些花給我媽媽。
  說明：`para mi madre` 指出花這個動作的接收者。

- **觀點／立場：** *Para los expertos, el cambio climático es urgente.*
  對專家來說，氣候變遷是個急迫的問題。
  說明：`para` 引出說話者所代表或引述的觀點立場。

- **方向／目的地：** *El tren sale para Barcelona a las ocho.*
  火車八點出發前往巴塞隆納。
  說明：`para` 表示移動的終點方向。

- **截止期限：** *Tengo que terminar el proyecto para el lunes.*
  我必須在星期一之前完成這個專案。
  說明：`para` 標出完成動作的最後期限。

- **與 por 對比：** *Estudio para aprobar el examen, no por obligación.*
  我學習是為了通過考試，不是出於義務。
  說明：前半句 `para aprobar` 說明目的（為了通過），後半句 `por obligación` 說明原因（出於義務），清楚對比兩者用法差異。

## 延伸學習

- **同義詞：** `a fin de`（為了，書面語中可替換表目的的 `para`）、`con el objetivo de`（以⋯為目標，較正式的替換說法）
- **反義詞：** `por`（因為、由於，與 `para` 在目的 vs 原因的對照上構成最常見的一組對比，但兩者並非真正的反義詞）
