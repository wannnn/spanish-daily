## 基本資訊

- **單字：** vosotros
- **中文意思：**
  1. 你們（西班牙半島用法，第二人稱複數**非正式**主格代名詞，指男性或男女混合的群體）
  2. 你們（介系詞後受詞形式）
- **詞性：** 代名詞

## 用法

- `vosotros` 是**西班牙半島西班牙語**中第二人稱複數的**非正式**主格代名詞，用於對兩個以上、彼此熟識並以 `tú` 稱呼的人說話，相當於中文的「你們」，例如 `Vosotros sois mis mejores amigos.`（你們是我最好的朋友。）
- 陰性形式為 `vosotras`：若聽者全為女性則用 `vosotras`；只要群體中有一位男性，或性別不確定，就用 `vosotros`。
- **地域差異（重要）：** `vosotros` 僅見於西班牙本土的西班牙語；**拉丁美洲**完全不使用 `vosotros`，不分正式或非正式，一律以 `ustedes` 指複數的「你們」。學習哪個地區的西語，會直接決定要不要使用這個字。
- 與 `tú`／`usted` 相同，西語動詞字尾已能標示人稱與單複數，主詞代名詞**常省略**：`¿Adónde vais?`（你們要去哪裡？）已足夠清楚；只有強調、對比，或需要釐清聽者範圍時才會明說 `vosotros`。
- `vosotros` 搭配的動詞使用專屬的「vosotros 形」變化，字尾常見 `-áis`／`-éis`／`-ís`，命令式則是 `-ad`／`-ed`／`-id`，是西語中辨識度最高的人稱字尾之一（詳見詞形變化）。
- 常見搭配：
  - `vosotros mismos`（你們自己，例如 `Podéis hacerlo vosotros mismos.`「你們自己就能做到。」）
  - `entre vosotros`（在你們之間）
  - `con vosotros`（跟你們一起）
- 常見固定表達：
  - `¿Y vosotros?`（那你們呢？，追問或轉移話題）
  - `vosotros dos`（你們兩個）
- 容易混淆的詞：
  - `vosotros`（西班牙非正式複數）vs `ustedes`（拉美通用、也是各地正式場合的複數第二人稱）：若不確定對方來自哪個西語地區，用 `ustedes` 更保險、通用性更高。
  - `vosotros`（主格／介系詞後形式）vs `os`（直接／間接受詞、反身代名詞）：兩者形式完全不同，如同 `tú` 與 `te` 的關係。
- 學習者常見錯誤：
  - 在拉丁美洲語境中使用 `vosotros`，母語者會覺得非常古典、書面或不合時宜（西班牙以外多見於文學、宗教文本），與當地口語不符。
  - 誤以為受詞也用 `vosotros`，寫出 `Vi vosotros ayer.`，正確應為 `Os vi ayer.`（我昨天看到你們了。）

## 詞形變化

`vosotros` 是第二人稱複數、**非正式**的代名詞，僅用於西班牙半島西語；依用途與陰陽性整理如下：

| 用途 | 陽性／混合 | 陰性（全體女性） |
|---|---|---|
| 主格（主詞） | **vosotros**（你們） | vosotras |
| 直接／間接受詞 | os | os |
| 反身代名詞 | os | os |
| 介系詞後形式 | vosotros | vosotras |
| 所有格形容詞 | vuestro／vuestra／vuestros／vuestras | 同左 |

對照其他人稱：

| 人稱 | 主格 | 受詞／反身 | 介系詞後 |
|---|---|---|---|
| 第二人稱單數非正式 | tú | te | ti |
| 第二人稱單數正式 | usted | lo／la／le／se | usted |
| 第二人稱複數非正式（僅西班牙） | **vosotros／vosotras** | os | vosotros／vosotras |
| 第二人稱複數正式，或拉美各地通用 | ustedes | los／las／les／se | ustedes |

`vosotros` 觸發專屬的動詞字尾變化，以規則動詞 `hablar` 為例（僅供對照，非窮舉所有時態）：

| 時態 | vosotros 形 |
|---|---|
| Presente | habláis |
| Pretérito | hablasteis |
| Imperfecto | hablabais |
| Perfecto | habéis hablado |
| Futuro | hablaréis |
| Condicional | hablaríais |
| Subjuntivo Presente | habléis |
| Imperativo | hablad |

## 例句

- **現在式，一般省略主詞：** *¿Adónde vais este fin de semana?*
  你們這個週末要去哪裡？
  說明：動詞 `vais` 的字尾已標示為第二人稱複數，語境清楚時不需加上 `vosotros`。

- **現在式，強調或釐清所指群體：** *Vosotros ya lo sabéis, pero ellos no.*
  你們已經知道了，但他們不知道。
  說明：明說 `vosotros` 是為了與後半句的 `ellos` 對比，清楚區分兩個不同群體。

- **命令式（Imperativo），對群體發出指令：** *¡Venid aquí, chicos!*
  你們過來這裡，各位！
  說明：`venid` 是 `venir` 的 vosotros 命令式，是日常對一群熟人下指令時最典型的用法。

- **過去式（Pretérito），詢問經歷：** *¿Vosotras fuisteis a la playa ayer?*
  你們（女生們）昨天去海邊了嗎？
  說明：全體聽者為女性，故用陰性 `vosotras`；動詞 `fuisteis` 是 `ir` 的 vosotros 過去式。

- **受詞形式 `os`：** *Os llamaré en cuanto llegue.*
  我一到就打電話給你們。
  說明：`vosotros` 作受詞時必須改用 `os`，不能直接說 `Llamaré vosotros`。

- **介系詞後直接使用 `vosotros`：** *Este regalo es para vosotros.*
  這份禮物是給你們的。
  說明：介系詞 `para` 之後直接接 `vosotros`，形式與主格相同，這點與 `tú`／`ti` 的變化不同。

## 延伸學習

- **同義詞：** 無真正同義詞；同樣指複數第二人稱時可改用 `ustedes`（拉丁美洲通用，或任何地區的正式場合），但語域與地域用法不同，並非單純替換。
- **反義詞：** 不適用（人稱代名詞無反義詞概念）；可與陰性 `vosotras`、單數 `tú`／`usted`，以及跨地域對應的 `ustedes` 對照理解。
